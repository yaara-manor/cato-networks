# Cato's Demo Account

## Overview

Cato’s Demo Mode lets you explore the Cato Management Application (CMA) using a realistic, interactive account. It's designed to simulate a live customer environment with constantly changing, lifelike data and sample scenarios that demonstrate Cato’s converged platform in action.

You can preview how all features look and behave after configuration, including all features that require additional licenses. This helps you understand how Cato's solutions fit together into a unified platform.

The Demo Mode account is read-only, so you can view all policies and pages, but can't make any changes.

## Accessing Demo Mode

Demo Mode is a standalone account that can be accessed directly from your account.

1. In the CMA, open the **Ask AI** panel.
2. Under **Discover and Learn**, click **Demo Mode**.

The Demo Mode environment opens in a new tab. It opens on the same page you were viewing when you clicked Demo Mode.

## Using the Guided Walkthroughs

When Demo Mode opens, a guided walkthrough overlay automatically appears on your screen. This guide helps you explore common use cases and understand how to perform key tasks in the CMA. Each walkthrough highlights a specific use case and automatically guides you through relevant CMA pages.

![demo_mode.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/32184597195293(1).png)

**To use the guided walkthroughs:**

1. In the overlay, select a walkthrough using the **radio button** next to it.
2. Click **Start** to begin the selected use case.
3. Follow the on-screen prompts and navigate through the CMA as directed.
4. To **minimize** the guide, click the close (**×**) icon in the overlay. A green **Cato icon** remains visible in the lower-right corner of the screen, allowing you to reopen the guide at any time.

We are always trying to improve, so please use the **Feedback** button in the guided walkthrough to let us know what you think.
