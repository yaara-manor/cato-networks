# Connecting the Cato Cloud to an AWS Transit Gateway

AWS Transit Gateway lets you connect multiple VPCs and on-premise assets through a central hub.

## Overview

AWS Transit Gateway is a service that lets you connect all of your network assets, VPCs, on-premise networks, and other through a centralized router.

Cato supports connecting to an AWS Transit Gateways for the following site types:

- IPsec
- Cloud Interconnect

To connect your Cato account to an AWS Transit gateway, read the following:

- [Setting up a Cato-initiated IPsec to your AWS Transit Gateway](/v1/docs/setting-up-a-cato-initiated-ipsec-to-your-aws-transit-gateway)
- [Setting up AWS Transit Gateway with Cloud Interconnect](/v1/docs/cloud-interconnect-for-aws-public-cloud)
