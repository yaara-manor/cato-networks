# Customizing Browser Application Portal

The **Application Portal** page lets Cato accounts customize the logo for the [Browser Access](/v1/docs/browser-application-portal-overview-securing-remote-access-to-applications) applications portal.

These are the specifications for the logo:

- Supported file types: JPEG and PNG
- Maximum file size is 200KB
- Recommended logo size is 150 x 100 px
- We recommend that you use logos with a transparent background

![Branding_Application_Portal.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24198379878301.png)

**To customize the Application Portal for your account:**

1. From the navigation menu, select **Account > Application Portal**.
2. To upload a file for the **Application Portal logo**, click the image or drag and drop the file to the image.
3. Click **Save**.
4. To remove all the customized email settings and replace them with the standard Cato Networks settings, click **Restore defaults**.
