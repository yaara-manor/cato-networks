# Customizing the Warning / Block Page Branding

This article discusses how to customize the branding of the Warning / Block page.

## Overview

When users try to go to a resource that matches a security rule with the **Block** or **Prompt** action, they are instead redirected to a webpage that explains why they can't directly access the resource. The default Warning / Block webpage uses the Cato logo, branding, and wording. This can be customized to include a logo, background color, button color, and font, to meet the requirements of your company. You can change the text in the notification and apply it to specific security policy rules. For more information, see [Creating User Notification Templates](/v1/docs/creating-user-notification-templates).

### Use Case: Branded Block Pages for Security Enforcement

An enterprise enforces security policies that block or prompt access to certain internet resources due to security, compliance, or acceptable use requirements. When users are blocked, the default warning page displays generic Cato branding and messaging, which can confuse users or feel disconnected from internal company policies.

The IT team customizes the Warning and Block webpages to reflect the company’s branding. When a user attempts to access a resource that matches a security rule with a Block or Prompt action, they are redirected to a branded webpage.

Users immediately recognize the page as an official company message, which reduces confusion and mistrust. Clear, policy-aligned messaging educates employees at the moment of enforcement, lowers the volume of support requests, and reinforces corporate security standards while maintaining a consistent, professional user experience.

## Customizing the Warning / Block Page Branding

The branding of the Warning / Block page applies globally; however some customizations can be changed in a User Notification Template. For more information, see [Creating User Notification Templates](/v1/docs/creating-user-notification-templates).

**To customize the Warning / Block Page:**

1. From the navigation menu, select **Account > Warning Block Page**.
2. Customize the Warning / Block Page as required.
3. Click **Save**.
