# Defining Default Working Hours for the Account

You can set default working days and hours for your account, or for specific sites. The working hours for each site is configured for it's own relative time zone. For example, you can configure firewall rules to only be active during the working hours for the sites.

For SDP users, the geo-location of the public IP address for the Cato Client determines the time zone.

## Configuring the Default Working Hours for All Sites

You can use the System Settings screen to configure the default working hours that are applied to all sites in your account.

![working_hours.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24198361889437.png)

**To define the default working hours for the account:**

1. From the navigation menu, click **Resources > System Settings**.
2. Set the **Hours** and **Days** for the account.
3. Click **Save**.

## Customizing Working Hours for a Specific Site

You can override the account working hours and customize working hours for a specific site.

**To customize working hours for a specific site:**

1. From the navigation menu, click **Network > Sites** and select the site.
2. From the navigation menu, click **Site Configuration > General**.
3. Expand the **Working Hours** section.
4. Select **Override account working hours**.
5. Set the **Hours** and **Days** for the account.
6. Click **Save**.

The working hours are set for that specific site.
