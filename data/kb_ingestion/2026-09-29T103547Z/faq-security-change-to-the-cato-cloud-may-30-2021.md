# FAQ - Security Change to the Cato Cloud (May 30, 2021)

**Why is Cato making this change?**

Cato PoP location in China block outbound Internet traffic on ports 135, 137, 138, 139, AND 445 (this traffic includes Dcom, NetBios, and SMB). If necessary, you can contact Cato Support and request to allow this traffic.

**What is impacted by this change?**

Outbound Internet traffic, for both sites and remote users, with destination ports 135, 137, 138, 139, 445. There is no impact to WAN or LAN traffic (because this traffic doesn't go to the Internet).

**What should I do if I have additional questions?**

Please contact Cato [Support](https://support.catonetworks.com/hc/en-us/requests/new).
