# How To Enable Debug Mode | Windows Client

This guide will explain how to enable Cato Windows Client to run with debug mode.

1. Browse the Cato Client installation folder - Run the Log Level Setup Application (LogLevelSetup.exe)

![](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/13972890192413.png)
2. Change all modules to DBG as well as LogLevelFile and press Save.

![](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/13972892714269.png)
3. Once you finish your reproduction, you should revert the changes and save again, or use the "Set Default Levels" to do it automatically.

**Important to use this only when instructed by the Cato Support team to avoid performance impact, and as mentioned in (3), revert the changes once done.**
