# Insights

Insights capabilities provide visibility and operational insights across applications, users, sites, and devices connected to the Cato Cloud.

They enable monitoring, analysis, and proactive operational awareness across the entire deployment, covering both remote users and on-site environments.

## DEM

Digital Experience Monitoring (DEM) provides visibility into user and application experience across the Cato Cloud, covering both users and sites. It enables organizations to monitor performance, identify degradation, and troubleshoot issues affecting users, applications, and network paths.

### Capabilities

- Monitors ZTNA user, on-site user and application experience
- Real-time visibility into performance and availability
- Proactive troubleshooting using traffic analysis and synthetic probing
- Correlates user experience with network and application behavior

### Licensing

DEM is licensed by users. Users represent the total number of users monitored across the Cato Cloud, regardless of whether they connect remotely or from behind a site.

The licensed quantity is typically aligned with the number of business SaaS users in the organization, for example, Microsoft 365 users.

## XOps

XOps provides advanced operational and security insights, along with automated actions for network and security events across the Cato Cloud. It enables organizations to monitor, analyze, and respond to events affecting users, sites, assets, and applications from a centralized platform.

### Capabilities

- Advanced analytics and insights for network and security events
- Correlates events across users, sites, assets, and applications
- Automated actions and workflows for incident response and remediation
- Centralized visibility and operational control through the CMA

### Licensing

XOps is licensed based on Bandwidth Pool (sites) and ZTNA Users.

The licensed quantity must cover the total bandwidth and ZTNA Users across all region groups.

Usage and fair use follow the measurement of the underlying Base Products
