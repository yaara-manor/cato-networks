# Installing the Cato Certificate on Android Devices

This article explains how to install the Cato Certificate on an Android device.

## Overview

When using the Cato SDP Client, we recommend that you install the Cato CA certificate on the device to provide the best security and user experience. In addition, depending on the settings for your organization, the Cato certificate is required to connect to the network.

System admins can download the Cato certificate and use a Device Management system to distribute and install it on Android devices with no action required by the end-user. If necessary, end-users can download and manually install the Cato certificate as a trusted certificate for the Android device.

## Installing the Cato Certificate

To install the Cato Certificate, first download the certificate and then install it on your device.

**To install the Cato certificate on an Android device:**

1. Download the Cato certificate from the [Client download portal.](https://clientdownload.catonetworks.com/)

![Android.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24218297274653.png)
2. On the Android device, navigate to **Settings > Password & security > System security**.

![Password_and_Security.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24218292290845.png)
3. Click **Credential Storage > Install certificates from storage > CA certificate**.

![CA_Cert.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24218278992669.png)
4. Click **Install anyway**.

![Install_anyway.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24218297503389.png)
5. Select the Cato Certificate.

![Cato_Cert.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24218308757149.png)

The Cato certificate is installed on your device.
