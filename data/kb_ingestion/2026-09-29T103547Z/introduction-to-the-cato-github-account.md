# Introduction to the Cato GitHub Account

## Overview

Cato Networks provides a GitHub account with tools you can use to interact with the Cato platform, either through the API, CLI, or Terraform.

The account is located at [https://github.com/catonetworks](https://github.com/catonetworks) and includes multiple repositories such as sample Python scripts, Postman Collections, and Jupiter notebooks.

It also includes useful tools such as CLI, API Explorer, as well as the Terraform provider code and Terraform modules. You can also learn about [Generating Custom Analytics Using Cato CLI for API Queries](/v1/docs/generating-custom-analytics-using-cato-cli-for-api-queries).

For example, the account contains an MCP server that integrates Cato's API with AI, allowing you to interact with your account using natural language questions.
