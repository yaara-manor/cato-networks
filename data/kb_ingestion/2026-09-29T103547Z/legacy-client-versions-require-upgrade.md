# Legacy Client Versions Require Upgrade

## Overview

On Oct 30, 2025, we discovered that the following specific versions of the legacy Cato Client are used by some of our customers and require an upgrade to reestablish connectivity due to a bug identified in the specific versions listed below.

- Windows Clients with versions running v5.9 or lower
- macOS Clients with versions running v5.5 or lower
- iOS Clients with versions running v5.1 or lower
- Android Clients with versions running v5.1 or lower
- Linux Clients with versions running v5.1 or lower

## What Changes Do I Need to Make?

Please use the [Access Overview Dashboard](/v1/docs/using-the-access-overview-page) to identify users who are using these versions. To continue using the Client, please upgrade to the latest version, which can be found at [https://clientdownload.catonetworks.com](https://clientdownload.catonetworks.com/).

## What is the Impact on the Account?

For users who do not upgrade, the Client will no longer connect to the Cato Cloud.
