# Manually Upgrade your EPP Agents

We have identified that some devices in your organization are using EPP agent version 1.1.6 or below, which are outdated versions of the EPP agent.

These versions cannot be automatically upgraded to the latest EPP version and must be upgraded manually to ensure your endpoints are protected with the most recent security enhancements and features.

Once your agents are running the latest version, they will be automatically upgraded to every new version released in the future.

You cannot register new EPP agents running version 1.1.6 or below after January 19, 2025.

## What Changes do I Need to Make?

You need to manually upgrade EPP agent versions 1.1.6 and below to the latest EPP agent [version](/v1/docs/summary-of-epp-agent-versions).

## What Happens If I Do Not Upgrade the EPP Agents?

If you do not upgrade EPP agents to the latest version, your endpoints are only protected with outdated features. While they are still receiving Anti-Malware updates, this may create a vulnerability in your environment.

## How Do I Know Which Endpoints are Running Outdated EPP Agent Versions?

On the **Access > Protected Endpoints** page (or **Monitoring > Protected Endpoints** page in the legacy navigation) you can view the agent version installed on each endpoint. You can sort by the **EPP Version** column.

## How Do I Manually Upgrade the EPP Agent?

For more information on how to manually upgrade your EPP agents, see [Managing the Endpoint Protection Solution](/v1/docs/managing-the-endpoint-protection-solution).
