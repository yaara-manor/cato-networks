# New Simplified Process for Onboarding Remote Users

Cato [announced](/v1/docs/product-update-july-1-2024) a new simplified onboarding process for remote users that authenticate with Username & Password or MFA. This process with begin gradual roll out on July 14, 2024.

In the new process users now create their password (and MFA) while signing into the Cato Client. For more information, see [Signing into the Cato Client](/v1/docs/signing-in-to-the-cato-client).

There is no impact on users who authenticate with SSO or existing users that authenticate with username & password, or MFA.

The following is a summary of the previous onboarding process compared to the new process.

| **Onboarding Process Before July 14, 2024** | **Onboarding Process After July 14, 2024** |
| --- | --- |
| 1. Admin creates a user in the Cato Management Application 2. (Optional) User immediately receives an activation email with a link to the User Portal 3. User creates their password (and MFA) in the User Portal 4. User can sign in to the Cato Client with their email and password | 1. Admin creates a user in the Cato Management Application* 2. In the Cato Client, the user enters their email and is sent an email with a link to the User Portal 3. User creates their password (and MFA) in the User Portal 4. User can sign in to the Cato Client with their email and password |

*You can choose to send a welcome email to new users with instructions and a link to download the Cato Client. For more information, see [Adding Users to Your Cato Account.](/v1/docs/adding-users-to-your-cato-account)

## Benefits of the New Onboarding Process

The new onboarding process lets users create their credentials in their own time in a unified experience. In the old process, users received an email at a time they did not choose and created their password as a separate process to sign in to the Cato Client.
