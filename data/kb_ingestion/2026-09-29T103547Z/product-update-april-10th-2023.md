# Product Update - April 10th, 2023

## New Features & Enhancements

- **AWS vSockets Support New VM Instance Type:** We certified an additional VM instance type for [vSockets in AWS cloud](/v1/docs/deploying-an-aws-vsocket-site-manually) - **c5n.xlarge**. The new instance type provides better performance and is recommended for sites with 2Gbps bandwidth and higher.
