# Product Update - Aug 26, 2024

There are no new features or enhancements for the Cato service for this week. Take a look at these great features that we released over the past few weeks:

- **Greater Flexibility to Handle Untrusted Certificates with TLS Inspection:** [TLS Inspection](/v1/docs/configuring-tls-inspection-policy-for-the-account) provides the ability to inspect encrypted traffic for malware, [CASB app control](/v1/docs/what-is-the-unified-casb-solution), and [DLP data control](/v1/docs/what-is-the-cato-dlp-service). For traffic that is using an untrusted certificate, you can define the applied action on a per-rule basis. For example, your general corporate approach is to block traffic that uses untrusted certificates, but you create a rule that is an exception for external contractors using private certificates.
- **Always-On - Stay Connected Even After Authentication Expires:** Cato’s [Always-On](/v1/docs/protecting-users-with-always-on-security) policy ensures that users are connected to a secure network and always maintain a strong security posture. The [Confidence Level](/v1/docs/remote-internet-security-with-one-time-authentication) setting in the [Client Connectivity Policy](/v1/docs/what-is-the-client-connectivity-policy) lets the specified users continue to access the Internet with just a one-time authentication. This ensures users always have Internet connectivity and protection with a great end-user experience. Requires Windows Client v5.9 and higher.
