# Product Update - August 12, 2024

- **Enhancements for EDM Profiles for DLP:** We streamlined the configuration of [Exact Data Matching (EDM)](/v1/docs/working-with-exact-data-matching-edm-for-dlp) profiles with the following improvements:
  - **New File Formats:** We added support for additional file formats for the data sets used to create EDM profiles.
    - New file formats include: TSV, PSV, SSV, HSV, TXT
    - Previously, only CSV files were supported
  - **Confirmation for Imported Data:** When you upload a file you can see how many rows of data were imported. This helps you identify issues when importing a data set.
- **New Best Practices Article for Logging Events:** We added a [new Knowledge Base article](/v1/docs/best-practices-for-cato-event-logs-and-ingestion) that describes the recommended best practices for Cato customers to optimize event log storage and SIEM ingestion processes.
- **Cato Enhancements:**
  - **Updated Thresholds for Network Stories in XDR:** To reduce false positives and help you focus on meaningful network stories, we updated the thresholds for creating [HA Not Ready stories](/v1/docs/xops-network-playbook-ha-status-is-not-ready).

Go to the [Cato Product Roadmap](https://bit.ly/49aFEKU) in the Knowledge Base to follow the status of upcoming features and enhancements.
