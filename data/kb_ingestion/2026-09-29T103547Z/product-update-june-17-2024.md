# Product Update - June 17, 2024

## New Features & Enhancements

- **Introducing Enterprise-Grade Management for Internet Firewall:** Over the next few weeks, we are gradually rolling out a new [Internet Firewall policy](/v1/docs/managing-the-internet-firewall-policy) that introduces several improvements, including:
  - Ability to modify the Internet Firewall policy in parallel by multiple admins
  - Faster and more responsive page for a large number of rules
  - API support for managing the Internet Firewall policy
- **New TLS Inspection Report:** We added a new [TLS Inspection Report Type](/v1/docs/generating-a-tls-inspection-report) to help you evaluate your TLS Inspection policy and identify significant traffic patterns and potential security risks. The report provides data such as total number of inspected and bypassed traffic flows per operating system, and top inspected and bypassed domains and apps.
  - The report data is based on generated events
- **Hit Count Reports for Security and Network Rules:** For better visibility and management of your policies, we added [new report types](/v1/docs/generating-rule-hit-count-reports-for-security-and-network-policies) that show the rule hit count during the report period.
  - Hit count reports are available for these policies: Internet Firewall, WAN Firewall, and Network Rules
  - The hit count is based on generated events
- **Enhancement for Experience Monitoring:** Over the next few weeks, we are gradually adding [new data](/v1/docs/using-the-experience-monitoring-page) to the Monitoring > Experience Monitoring page to increase the visibility of the application experience of your users
  - Aggregates multiple instances of a user into a single row (ie. device name vs user name), regardless of the user location
