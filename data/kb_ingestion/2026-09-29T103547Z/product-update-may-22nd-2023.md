# Product Update - May 22nd, 2023

## New Features & Enhancements

- **PDF Reports Highlight Application Traffic:** Now you can generate [Application Analytics reports](/v1/docs/generating-an-application-analytics-report) that show an overview of application usage in your account, including:
  - Top applications
  - Risk levels
  - Sanctioned vs. Unsanctioned apps
  - Application categories
- **Cato Management Application Enhancement:**
  - **Routing Table Filters**: Over the next few weeks, we are adding a new filter to the [Routing Table](/v1/docs/showing-the-routing-table-for-your-account) screen to filter routes for SDP users. This filter is set by default to reduce the number of displayed items.
