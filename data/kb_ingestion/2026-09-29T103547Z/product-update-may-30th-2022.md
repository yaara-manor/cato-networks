# Product Update - May 30th, 2022

## New Features & Enhancements

- **New SDP Users Overview Screen:** We added a new screen that lets you scroll and see a summary of the analytics for each SDP user in your account (Monitoring > SDP Users Overview). [Read more](/v1/docs/showing-user-analytics-with-sdp-users-overview).
  - One click drills-down and shows in-depth analytics for that user.
- **Enhancement for Group Descriptions in the Cato Management Application:** The list of groups in a drop-down menu now includes the description for each group.
- **Added Description Field for Firewall Rules:** You can add a description to the Internet and WAN firewall rules. The description is visible when you edit a rule in the right-hand panel.

## Cato SDP Client Releases

- **Windows Client v5.3:** Windows Client version 5.3 is now available to download from the [Cato Users Portal](https://myvpn.catonetworks.com/login).
  - You can read more about the details for this Client version [here](/v1/docs/product-update-april-18th-2022).
