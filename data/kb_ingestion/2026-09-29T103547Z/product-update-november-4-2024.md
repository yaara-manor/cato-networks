# Product Update - November 4, 2024

## New Features & Enhancements

- **Digital Experience Monitoring for App Performance and User Experience:** We are releasing new enhancements to [Digital Experience Monitoring](/v1/docs/what-is-cato-experience-monitoring) (DEM), which proactively monitors the performance of sites, users, and apps. New features include:
  - [Network path analysis](/v1/docs/experience-monitoring-connection-details) to pinpoint issues for sites and users
    - DEM for remote users requires installing the Cato Client
  - Identify user experience [anomalies](/v1/docs/analyzing-experience-monitoring-anomalies) in your account
  - Create scheduled [reports](/v1/docs/generating-dem-site-experience-reports) that summarize the overall account experience and highlight top issues
  - An additional license is required for DEM features
- **AI-Based Natural Language Search for Events**: We added a [new search capability](/v1/docs/using-natural-language-search) to the Events page that lets you search and filter event data using everyday language instead of keywords and fields. For example, you can request to “show today’s risky inbound traffic”, and the AI engine automatically applies the relevant filters to show the events.
  - You can search events with AI or continue to use the previous filters
  - Supports searches in English
- **Windows Client v5.12**: From November 3, 2024, we are starting the rollout of [Windows Client version 5.12](/v1/docs/summary-of-cato-windows-client-releases). This version contains bug fixes and enhancements, including:
  - Enabling the Always-On policy with [the registry key](/v1/docs/protecting-users-with-always-on-security) blocked access to Microsoft Self-Service Password Reset from the lock screen
- **New PoP Location for Cloud Interconnect:** A new PoP for [Cloud Interconnect](/v1/docs/getting-started-with-cloud-interconnect-sites) in Osaka is now available to immediately connect a site, expanding connectivity and access in the Far East region.
- **Join Our Live Session with API Experts in Cato Academy:** Explore the Cato API with a hands-on demonstration, from onboarding to operations, and engage directly with our experts in an AMA session. [Register here](https://academy.catonetworks.com/live-ama-about-api)

## PoP Announcements
