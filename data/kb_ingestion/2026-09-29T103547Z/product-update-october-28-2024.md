# Product Update - October 28, 2024

- **New EPP Agent v1.2:** From the week of October 27, 2024, we are starting to roll out Endpoint Protection (EPP) [Agent version 1.2](/v1/docs/summary-of-epp-agent-versions). This version includes:
  - Support for Windows Servers 2022, 2019, and 2016
  - Bug fixes and enhancements, including:
    - Improved error messages
    - In the agent, the **Full system scan** button is enabled only with an EPP license
  - Click [here](https://academy.catonetworks.com/epp-agent-v12/201606) to watch a video recording of this feature
- **Enhanced Admin Experience for Managing Policies at Scale:** In the past few months, we introduced enhanced policies for the [WAN Firewall](/v1/docs/what-is-the-cato-wan-firewall), [Internet Firewall](/v1/docs/what-is-the-cato-internet-firewall), and IP Allocation for Clients (EA) that include:
  - API support for managing the policy with a consistent structure between the above policies For more information see the [Cato GraphQL API Reference](https://api.catonetworks.com/documentation/#introduction)
  - Ability to [modify the policy](/v1/docs/working-with-policy-revisions) in parallel by multiple admins
  - Faster and more responsive page for policies with many rules
