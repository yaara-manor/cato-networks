# Product Updates - January 26, 2026

## New Features & Enhancements

- **DEM Enhancements for Zoom Integration:** To better indicate end-user experience issues with UCaaS applications, [Zoom metrics](/v1/docs/the-user-experience-monitoring-drill-down-page-remote-and-office-users) on the Experience Monitoring page are now displayed as minute-by-minute data instead of aggregated call summaries. This lets you more precisely detect and troubleshoot degraded user experience.
  - Requires a DEM license
- ​**DLP Supports Google Labels:** [Google labels](/v1/docs/using-google-labels-with-the-data-protection-api) integration allows you to leverage existing Google Drive classifications to automatically detect labeled files and enforce DLP protection policies. This ensures stronger compliance and more accurate data protection by extending Google’s native labeling across your security controls.
  - SaaS Security API license is required
- **Cloud Interconnect Support for BGP Communities on the Default Route:** When advertising the default route to [Cloud Interconnect sites](/v1/docs/cloud-interconnect-sites), you can now add BGP communities. This gives admins more granular control over how return-path routing is handled on third-party networks that rely on BGP community tags for routing decisions.
  - Supported for Cloud Interconnect sites only
- **New iOS Client v5.7**: During the week of January 25, 2006, the iOS Client v5.7 will be available to download from the App Store. This version includes:
  - Support for iOS 26
  - Stability improvements
  - Security updates
  - Bug fixes
