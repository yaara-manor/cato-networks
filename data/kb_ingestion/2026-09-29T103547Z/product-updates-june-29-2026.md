# Product Updates - June 29, 2026

## New Features & Enhancements

- **Identify and Prevent Risks in SaaS Application Configurations:** Cato’s SaaS Security Posture Management (SSPM) provides visibility into posture gaps, misconfigurations, and exposure risks that can make your SaaS environment vulnerable to attack. This capability complements Interconnected Apps and helps security teams continuously assess SaaS application posture and reduce risk.
  - Currently supported for Microsoft 365, Slack, Google Workspace, and more
  - CASB license required
- **Start with Ask AI for Faster Support:** Clicking **Submit a Request** in the Knowledge Base opens the AI Workspace in the Cato Management Application in a new tab. Describe what you need help with, and Ask AI helps you resolve issues faster with guided answers, account context, and relevant Knowledge Base articles.
- **New macOS Client v6.0.1**: During the week of June 28, 2026, we are rolling out macOS Client version 6.0.1. This version includes Bug fixes, security enhancements, and stability improvements.
- **AI Runtime Protection Events for SIEM Integrations:** When Cato AI Security detects a violation of the Guards Policy, it now generates AI Runtime Protection events for visibility into risky AI usage. Export these events to your SIEM using Cato event integrations, helping SOC teams investigate AI policy violations alongside other security events.
  - AI Security for Applications license required
- **Application Control via API - Support for Gmail:** Connecting SaaS apps to Cato lets you understand who is accessing each app and identify suspicious activities or trends, even when users are not connected to the Cato Cloud. You can now connect the Gmail tenant to provide visibility into user activities.
  - The Gmail connector is available from the **Integrations Catalog**, under **App Activities**
  - CASB license required
