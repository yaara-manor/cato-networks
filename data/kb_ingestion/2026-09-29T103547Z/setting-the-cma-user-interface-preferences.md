# Setting the CMA User Interface Preferences

This article discusses the preferences for the Cato Management Application (CMA) that you can select in the Profile panel.

## Overview of CMA User Interface Preferences

Each admin can customize their preferences for the CMA, including the localization options, and the layout for the navigation menus.

![myprofile.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24198310693405.png)

### Changing the Localization Settings

The CMA uses AI-powered translation to support localization and translate the pages to different languages. Use the Profile panel to change the **Language** for the menu options and messages.

These are the supported languages:

- Bengali
- French
- Hindi
- Japanese
- Korean
- Mandarin (Simplified) Chinese
- Portuguese
- Russian
- Spanish

**Known Limitations for Localization**

- Content that is provided from external sources is not translated. For example, the app descriptions in the [Apps Catalog](/v1/docs/using-the-app-catalog).
- Error messages aren't translated
- New pages and features can take a few weeks before they are localized

### Choosing the Light Mode

The CMA can be displayed in either light mode (with a white background) or dark mode (with a black and grey background). You can customize the colors used in light mode and dark mode. For more information, see [Customizing the CMA](/v1/docs/customizing-the-cma).

### Changing the Homepage

By default, when admins log in to the CMA, they see the Home > Topology page. Each admin can define a custom homepage that opens when they log in to the CMA.

## Setting the CMA User Interface Preferences

Open the Profile panel and set the admin preferences for the CMA. The Profile icon in the CMA generally displays the initials of the user.

**To set the CMA user interface preferences:**

1. On the CMA top menu-bar, click the Profile icon. The panel opens and shows the admin preferences.
2. In **Light Mode**, select the light or dark mode theme for pages.
3. In **Language**, select the localized language for the CMA menu options and messages.
4. To change the homepage:
  1. Navigate to the new homepage.
  2. From the Profile menu, click **Set current page as homepage**.
5. You can click **My Profile** to open the [Administrators](/v1/docs/managing-admins) page for the admin.
