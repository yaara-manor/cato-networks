# Showing User Analytics with SDP Users Overview

This article discusses how to use the SDP Users Overview page to show analytics for all the SDP users in your account.

## Analyzing Traffic with the SDP Users Overview Page

The SDP Users Overview page shows analytics and Client traffic data for all SDP users in your account. With one click, you can drill-down and show the User Monitoring > Network Analytics page already filtered for the user and time range.

The SDP Users Overview page also highlights Client connectivity issues for each user.

![All_SDP_Users_Overview.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24275687829277.png)

**To show the SDP Users Overview page:**

- From the navigation menu, select **Access > SDP Users Overview**.

These are the actions you can perform in this screen:

- Throughput drop-down menu - Filter for the SDP user throughput: **Total Throughput**, **Upstream**, or **Downstream**
- ![Monitoring_Icon.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24275639815837.png) Monitoring icon - Opens the User Network > Network Analytics page to show analytics for that user
- ![Configuration_Icon.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/24275647686941.png) Configuration icon - Opens the Network > General page to configure settings for that user

### Using the Time Range Filter

Use the time range filter in the top right corner of the screen to display analytics for a specific duration. You can use one of the predefined time ranges, or customize your own time range. To read more, see [Setting the Time Range Filter](/v1/docs/setting-the-time-range-filter).

## Drilling-Down to a Specific SDP User

You can easily drill-down and show in-depth analytics and data in the Network > Network Analytics for that SDP user:

- Click the Monitoring icon
- Click the SDP user

In addition, you can hover over the highlighted areas in the analytics graph to show the types of connectivity issues that occurred for the user.
