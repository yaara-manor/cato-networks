# Socket Version 11.0 Release Notes

Socket version 11.0 includes the following features:

- **High Availability for Azure vSockets:** The ability to add a secondary vSocket to Azure sites to provide redundancy for the site.
- **Stability improvements.**
- **Bug fixes.**
