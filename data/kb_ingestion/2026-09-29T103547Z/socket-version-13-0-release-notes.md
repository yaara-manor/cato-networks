# Socket Version 13.0 Release Notes

Socket version 13.0 includes the following features:

- Stability improvements
- Security updates
- Bug fixes

This version also includes the firmware for new features, and in the coming weeks we will update the Cato Cloud and release the following feature:

- **Local Routing with Source NAT:** Now supports the ability to create a local routing rule with the source NAT (hide NAT) option.
