# Socket Version 14.0 Release Notes

Socket version 14.0 includes the following features:

- Stability improvements
- Security updates
- Bug fixes

This version also includes the firmware for new features, and in the coming weeks we will update the Cato Cloud and release the following feature:

- **Enhancement to BGP for Azure vSocket HA:** Azure vSockets configured in an HA cluster will support BGP
