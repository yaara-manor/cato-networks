# Socket Version 18.0 Release Notes

Socket version 18 includes the following features:

- Stability improvements
- Security updates
- Bug fixes
- This version also includes the firmware for new features, and in the coming weeks we will update the Cato Cloud and release the following features:

- 
  - **LAN Firewall Policy:**
    - An enhanced version of the Local-routing policy with new configuration options to Allow/Block LAN communication between networks, hosts, services, and a new tracking option for monitoring LAN flows.
  - **Additional X1700 WAN Interfaces :**
    - Currently it's possible to configure up to three WAN ports on the X1700 Socket.
    - Starting with v18, the X1700 Socket supports four WAN ports.
