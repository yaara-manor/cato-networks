# Summary of Browser Extension Releases

This article summarizes the features and enhancements for the Cato Browser Extension for Chrome according to the specific version.

In addition, it also lists the known limitations.

The Browser Extension can be downloaded from the Chrome Web Store.

## Cato Browser Extension

This section summarizes the features and enhancements for Cato's Browser Extension.

### Browser Extension v1.9

During the week of September 6, 2026, Enterprise Browser v1.9 is available. This version contains bug fixes, stability improvements, and security enhancements.

### Browser Extension v1.8

During the week of May 10, 2026, Enterprise Browser v1.8 is available. This version contains:

- If a connection is lost, the Browser displays a spinner icon while automatically restoring the connection
- An automatic reconnection attempt can now be stopped with the Cancel button
- Stability improvements and security updates

### Browser Extension v1.1

From October 6, 2025, Cato is gradually releasing Browser Extension v1.1. This version includes the following:

#### New Features

Browser Extension v1.1 includes the following new features:

- Browser Extension WAN Access: The Cato Browser Extension now lets users securely access WAN applications (HTTPS) directly from their Chrome browser
- Improved monitoring for when the Browser Extension disconnects from the PoP

#### Requirements

Browser Extension v1.1 requires that [TLS Inspection](/v1/docs/tls-inspection) be enabled.

### Browser Extension v1.0

From March 31, 2025, the Cato Browser Extension is available from the Chrome Web Store.

You can now use the Cato Browser Extension to let authorized users access sensitive SaaS resources without installing the Cato Client, for example, for unmanaged devices. The Client Connectivity Policy lets you define who is allowed to use the Browser Extension, which ensures that adaptive access conditions are met.
