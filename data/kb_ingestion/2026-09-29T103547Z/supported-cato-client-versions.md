# Supported Cato Client Versions

This article lists the supported Cato Client versions and their End of Support (EOS) dates.

Cato supports Client releases for a year after their release date. Customers should upgrade to a supported version to receive security updates, bug fixes, and technical support. For more information, see [Cato Client End-of-Support](/v1/docs/end-of-support-eos-policy-for-cato-clients).

For more information about supported device operating system versions, see [Preparing to Install the Cato Client](/v1/docs/preparing-to-install-the-cato-client).
