# Understanding the Experience Monitoring Drill-Down Pages

This article explains how to use the Experience Monitoring drill-down pages to analyze performance and user experience in your network.

For more about reviewing analytics on the Experience Monitoring page, see [Using the Experience Monitoring Page](/v1/docs/using-the-experience-monitoring-page).

## Overview

You can click on an entity in the Experience Monitoring page to drill down and view specific analytics for application traffic related to that entity. You can then filter the analytics to show data for any of the individual applications used by the entity. These are the entity types you can drill down on these entity types: sites, users (remote and office), hosts, and applications.

The drill-down page for each entity type shows a set of widgets customized to help analyze application traffic for that entity type.

## Recommended Drill-Down Workflow

The following is a recommended workflow for analyzing application traffic with the drill-down pages:

1. In the **Select Application** widget, review the average experience scores for the top used applications to help identify applications experiencing issues.
2. In the **Select Application** widget, click on an application to filter the page to show data specific to that application.
3. Review the widgets showing basic data for the application, such as the average TTFB, download and upload usage, and top hosts using the application. Check the average experience score for the hosts.
4. Review the **Site Application Experience Score** widget to analyze performance over the configured time range.
5. Check the **Connection Details** for information about the different nodes in the network path.
6. Open the sections in **Connection Details** to drill down to detailed data and graphs relating to the performance of each node.
