# Using Segmentation Flows

## Overview

The Segmentation Flows widget uses a Sankey diagram to visually represent the protocols and destinations used by devices when accessing the Internet. This visualization helps you quickly understand traffic distribution and relationships for more informed segmentation and security policy decisions.

## Getting Started with the Segmentation Flow

![Segmentation_flow.png](https://cdn.document360.io/81d0367c-2b69-4ba8-b412-1c8f46ce677e/Images/Documentation/33981407812381.png)

The diagram displays traffic as flows between hierarchical levels. This includes:

- Device Type
- Application
- Protocol
- Destination (optional view)

The width of each connection represents the relative volume of traffic flowing between entities.

### Displaying the Segmentation Flow

You can display the Segmentation Flow by navigating to **Home > Devices > Segmentation** tab.

### Using the Segmentation Flow

The segmentation flow provides insight into:

- Which device types generate the most traffic
- Which applications are most used by specific device categories
- The protocol distribution per device type
- Traffic to specific destinations (when enabled)
